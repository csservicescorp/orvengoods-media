# ORVEN GOODS media

Instagram Reels for @orvengoods, made only from the store's own product photos (no AI imagery).

- `sync_products.py` (run locally) refreshes `data/products.json` and `images/<handle>/`.
- `make_reel.py` renders a 9:16 MP4 into `reels/`.
- The daily routine commits the Reel and gives Metricool the raw GitHub URL.

Fonts: Playfair Display and Inter, SIL Open Font License (see fonts/).
